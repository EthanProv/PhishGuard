# PhishGuard
Utilizar Apache SpamAssassin Public Corpus  y Nazario Phishing Corpus #Nazario Phishing para sacar correos que han sido spam/phishing y legitimos

Para entrenar el modelo se han utilizado datasets públicos de correos electrónicos. Para los correos spam y benignos se ha usado Apache SpamAssassin Public Corpus, que contiene mensajes clasificados como spam y ham. Para ejemplos específicos de phishing se ha considerado el Nazario Phishing Corpus, un conjunto público de correos phishing clasificados manualmente. Estos datos permiten que el sistema PHISHGUARD entrene con ejemplos más realistas que los correos simulados manualmente.
